# Portfolio cá nhân

Website giới thiệu bản thân và 3 dự án học tập, dành cho nhà tuyển 
dụng thực tập.

## Chạy dự án

Đây là website tĩnh, không cần cài đặt thư viện hoặc chạy lệnh build. Mở `index.html` trong trình duyệt để xem portfolio. Trang kết quả của form liên hệ nằm tại `ket-qua.html`.

## Cấu trúc repository

```text
.
├── assets/                 # Ảnh đại diện và hình minh họa dự án
├── css/                    # Stylesheet
├── docs/
│   ├── evidence/           # Minh chứng cho bài Buổi 7
│   ├── AI_LOG.md           # Nhật ký công việc
│   ├── RELEASE_NOTES.md    # Ghi chú phiên bản hiện có
│   └── evidence-index.md   # Danh mục minh chứng
├── CHANGELOG.md            # Lịch sử thay đổi
├── index.html              # Trang portfolio
└── ket-qua.html            # Trang kết quả form liên hệ
```

## Các bước mở
1. Mở trình duyệt (Chrome hoặc Edge), dán URL ở mục Demo vào thanh địa chỉ rồi nhấn Enter.
2. Chờ trang tải xong, trang chủ hiển thị tên "Nguyễn Văn An" và thanh menu ở trên cùng.
3. Bấm menu **Giới thiệu** để xem thông tin cá nhân.
4. Bấm menu **Kỹ năng** để xem danh sách kỹ năng.
5. Bấm menu **Dự án** để xem các dự án học tập.
6. Bấm menu **Học tập** để xem quá trình học.
7. Bấm menu **Liên hệ** để xem thông tin liên hệ ở cuối trang.
